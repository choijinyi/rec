이 부록은 게임 목록집이 아니라 **레퍼토리를 만들고 관리하는 방법**을 다룬다. 목록은 인터넷에도
많고 금세 낡지만, 자기 레퍼토리를 정리하는 체계는 오래간다.

## 1. 게임 카드의 표준 양식

게임 하나를 기록할 때 다음 항목을 채운다. 저자의 게임 자료가 쓰고 있는 서식을 따랐다.

| 항목 | 내용 |
|---|---|
| 게임명 | |
| 목적 | 이 게임을 왜 하는가 (한 줄) |
| 대상 | 연령, 인원, 조건 |
| 진행 단계 | 도입 / 전개 / 절정 / 마무리 |
| 카이와 범주 | 아곤 / 알레아 / 미미크리 / 일링크스 |
| 대형 | 원형 / 종대 / 횡대 / 밀집 / 자리 |
| 준비물 | |
| 진행 시간 | |
| 진행 절차 및 방법 | 번호를 매겨 순서대로 |
| 프로그램 변형 | 인원·공간·도구·감각·승부의 다섯 변수로 |
| 토의 사항 | 끝난 뒤 무엇을 나눌 것인가 |
| 주의 사항 | 안전, 소외 위험, 벌칙 |

**토의 사항 항목이 있다는 점이 중요하다.** 18장에서 짚었듯 게임이 끝난 뒤 무엇을 나눌 것인지가
미리 적혀 있으면 그 게임은 오락에서 교육으로 넘어간다.

## 2. 카드 작성 예시

| 항목 | 내용 |
|---|---|
| 게임명 | 이름 빙고 |
| 목적 | 서로의 이름을 익히고 첫 접촉을 만든다 |
| 대상 | 전 연령 / 15명 이상 / 처음 만난 집단 |
| 진행 단계 | 도입 |
| 카이와 범주 | 아곤(약함) |
| 대형 | 자유 이동 |
| 준비물 | A4 용지, 필기구 |
| 진행 시간 | 15분 |
| 진행 절차 및 방법 | ① 가로세로 표를 그린다. ② 첫 칸에 자기 이름을 쓴다. ③ 돌아다니며 다른 사람의 이름으로 나머지 칸을 채운다. 이름을 받으려면 먼저 자기 이름을 알려 준다. ④ 다 채우면 빙고를 진행한다. |
| 프로그램 변형 | 인원이 적으면 표를 작게 한다. 이동이 어려우면 앉은 자리에서 옆줄까지만 채운다. 이름 대신 좋아하는 것을 적게 하면 대화가 길어진다. |
| 토의 사항 | 이름을 묻는 일이 왜 어색한가. 처음 말을 건 사람은 누구였는가. |
| 주의 사항 | 이름을 아무에게도 받지 못한 사람이 생기지 않도록 관찰한다. |

## 3. 레퍼토리의 구성 — 최소 세트

모든 게임을 알 필요는 없다. 다음 조건을 채우는 **열두 개**를 확보하면 대부분의 상황을 감당할 수
있다.

| 자리 | 필요한 것 | 개수 |
|---|---|---|
| 도입 | 자리에서 하는 주의 집중 활동 | 2 |
| 도입 | 실패가 안전한 활동 | 1 |
| 도입 | 이름을 익히는 활동 | 1 |
| 전개 | 팀을 나누는 활동 | 1 |
| 전개 | 협동 과제 | 2 |
| 절정 | 팀 대항 활동 | 2 |
| 절정 | 대표자 활동 | 1 |
| 마무리 | 전체가 함께 닫는 활동 | 1 |
| 예비 | 도구 없이 목소리만으로 되는 활동 | 1 |

마지막 줄이 20장에서 강조한 위험 대비다. 음향과 준비물이 없을 때 쓸 수 있는 활동을 반드시 하나
갖고 있어야 한다.

## 4. 색인의 축

레퍼토리가 늘면 검색이 필요하다. 18장에서 정리한 일곱 기준에 이 책의 두 축을 더해 색인을 만든다.

- 장소 — 실내 / 실외 / 온라인
- 움직임 — 동적 / 정적
- 대형 — 원형 / 종대 / 횡대 / 밀집 / 자리
- 대상 — 유아 / 아동 / 청소년 / 성인 / 노년 / 혼합
- 목적 — 교육 / 친교 / 훈련 / 단합
- 인원 — 짝 / 팀 / 전체
- 계절
- **진행 단계** — 도입 / 전개 / 절정 / 마무리 (15장)
- **카이와 범주** — 아곤 / 알레아 / 미미크리 / 일링크스 (5장)

마지막 두 축이 이 책이 더하는 부분이다. 진행 단계 축은 게임을 어디에 놓을지 알려 주고, 카이와
축은 프로그램의 균형을 점검하게 해 준다. 자기 레퍼토리를 카이와 범주로 세어 보면 대개 아곤에
치우쳐 있다.

## 5. 활용 가능한 자료와 그 한계

저자의 자료 가운데 레퍼토리로 쓸 수 있는 것을 정리해 둔다.

**게임 자료집.** 게임마다 목적·진행절차·변형·토의사항·준비물·진행시간이 기록된 자료가 있다.
제목은 99가지이나 실제 수록은 38개다. 기업 교육용으로 만들어진 것이 많아 성인 대상에 적합하며,
소집단 토의형 활동이 강점이다.

**아이스브레이크 자료.** 인사하기, 이름 빙고, 교재에 이름 쓰기, 발음 게임, 두뇌 활동 문제가
실려 있다. 이미지 위주 슬라이드라 일부 활동은 그림 안에 설명이 있어 텍스트만으로는 복원되지
않는다.

**청소년 집회 자료.** 초성 퀴즈, 속담 퀴즈, 그림 연상 퀴즈를 팀 대항으로 구성한 대집단 진행
자료다. 문제 유형과 제한 시간, 진행 방식이 구체적으로 남아 있다.

**광주 레크과정 자료.** 네 단계별 활동 배치 시나리오가 실려 있다. 도입에 아이큐 테스트·규칙
발견 게임·큰공 작은공·가라사대, 전개에 가위바위보 열전·팀장 뽑기·팀 이름 정하기·릴레이 달리기,
절정에 무엇일까요·공통점을 찾아라·동물빙고·손가락 골프, 마무리에 잡아야 산다·조별 나누기가
배치되어 있다.

**14주차 강의안.** 청소년 대상 게임 다섯 종의 준비물과 진행 절차가 전문으로 실려 있다.

**한계와 갱신.** 18장에서 짚었듯 오래된 자료에는 오늘의 기준에서 부적절한 질문이나 설정이 섞여
있다. 성적인 소재, 특정 집단에 대한 견해를 공개적으로 밝히게 하는 질문, 사적인 영역을 캐묻는
항목이 그렇다. **부록으로 옮길 때 이 항목들은 반드시 교체해야 한다.** 게임의 구조는 유효하되
내용은 갱신되어야 한다.

## 6. 자기 레퍼토리를 만드는 절차

1. 지금까지 진행해 본 게임을 모두 적는다. 이름만이라도 좋다.
2. 각각을 표준 양식의 카드로 옮긴다. 한 번에 다 하지 말고 진행할 때마다 하나씩 만든다.
3. 진행한 뒤에 그 카드에 기록을 덧붙인다. 잘된 점, 안 된 점, 다음에 바꿀 것.
4. 색인의 축으로 분류하고 빈칸을 확인한다.
5. 빈칸을 채울 게임을 찾아 배운다.

이 절차의 값은 목록이 아니라 **기록의 축적**에 있다. 21장에서 정리했듯 남기지 않은 사람은
십 년을 일하고도 처음부터 설명해야 한다.
