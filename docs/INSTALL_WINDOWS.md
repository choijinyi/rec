# Windows 설치 안내 — 키움증권 REST API AI 단타

이 프로그램은 **AI 단타 자동매매** 전용이다. AI(Claude Fable)가 거래량·
등락률 상위에서 매매 종목을 자동 선정해 즉시 매수하고, 목표 수익
(+1~2%, 설정 가능)에서 익절, -3%에서 무조건 손절한 뒤 다음 종목을 찾아
반복한다. 장전부터 장후까지(국내 08:00~20:00, 미국 주간거래+정규장)
동작한다.

## 가장 쉬운 방법: 원클릭 설치

1. 저장소의 `scripts/AutoTrader-Setup.bat`를 바탕화면에 내려받아 더블클릭한다.
   (SmartScreen 경고가 뜨면 "추가 정보 → 실행")
2. 설치가 끝나면 메모장으로 `config.ini`가 열린다. 아래 "API 키 발급"에서
   받은 두 키를 붙여넣고 저장한다.
3. 바탕화면의 **"AutoTrader 실행"**을 더블클릭하면 브라우저에 대시보드가 열린다.

## API 키 발급 (키움증권, 최초 1회)

1. [openapi.kiwoom.com](https://openapi.kiwoom.com) 접속 → 키움 REST API 사용 신청.
2. 모의투자 신청 후 **모의투자용 appkey / secretkey** 발급.
3. `%USERPROFILE%\autotrader\config.ini`에 붙여넣는다:

   ```ini
   [kiwoom]
   appkey = 발급받은키
   secretkey = 발급받은시크릿
   mode = mock
   us_day_session = true   ; 미국주식을 한국 낮(주간거래)에도 매매

   [claude]
   backend = auto          ; AI 종목 선정: 키가 있으면 API, 없으면 구독 로그인
   api_key =
   ```

## AI 종목 선정: 구독 로그인 (API 과금 없음)

Claude API 키 대신 claude.ai **Pro/Max 구독**으로 선정을 돌릴 수 있다.

1. PowerShell에서 Claude Code 설치: `irm https://claude.ai/install.ps1 | iex`
2. `claude`를 한 번 실행해 claude.ai 계정으로 로그인 (브라우저 인증)
3. `[claude] api_key`는 비워 둔다 — 키가 없으면 자동으로 구독 로그인을 쓴다.

AI 백엔드가 전혀 없어도 매매는 멈추지 않는다 — 등락률 모멘텀 상위로
자동 대체된다.

## 사용 방법

대시보드에서 입력하는 값은 네 가지다.

| 항목 | 의미 |
|---|---|
| 시장 | 국내주식 / 미국주식 |
| 목표 수익 % | 1~2 권장. 이 수익률 도달 시 전량 익절 (손절은 -3% 고정) |
| 동시 종목 | 동시에 보유할 최대 종목 수 (슬롯당 예산 = 총액 ÷ 이 값) |
| 총 투입 금액 | 매수에 쓸 전체 금액 |

동작 규칙:

- AI가 2분 주기로 후보를 재탐색한다. 상승 모멘텀 종목만 후보가 되며,
  최근 매매한 종목은 30분간 다시 사지 않는다.
- 보유 종목이 60분 안에 익절/손절에 닿지 않으면 정리하고 교체한다.
- 당일 누적 손실이 총액의 6%에 달하거나 매매가 40회를 넘으면 신규 매수를
  멈춘다(보유 청산은 계속). 상태 카드에 멈춘 이유가 표시된다.
- 국내 장전(08:00~09:00)·장후(15:30~20:00)는 NXT 지정가로 집행된다.
  NXT 미거래 종목은 주문이 거부될 수 있고, 시간외는 호가가 얇을 수 있다.

## 실전투자 전환

1. openapi.kiwoom.com 에서 **실전용** appkey/secretkey를 발급받아
   `config.ini`에 입력하고 `mode = real`로 바꾼다.
2. 대시보드의 "실전 확인"란에 `YES`를 입력해야만 시작된다.

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "API 키가 없다" | `config.ini`에 appkey/secretkey 입력 여부 확인 |
| "토큰 발급 실패" | 키가 모드(모의/실전)와 일치하는지, REST API 승인 여부 확인 |
| 매수가 안 나감 | 장중인지, 상태 카드에 한도 도달 표시가 있는지 확인 |
| AI 선정이 "대체"로 나옴 | Claude Code 로그인 또는 [claude] api_key 확인 |
| Python 설치 후에도 인식 안 됨 | 컴퓨터 재시작 후 설치 파일 재실행 |

## 유의사항

- 이 프로그램은 수익을 보장하지 않는다. 단타는 매매가 잦아 수수료·호가
  비용이 빠르게 쌓이며, 통계적으로 수익을 내기 어려운 방식이다.
  반드시 모의투자에서 충분히 검증한 뒤 실전 전환을 검토하라.
- API 키는 `config.ini`(내 컴퓨터)에만 두고 절대 저장소·메일 등에 올리지 않는다.
- 자동매매 결과의 책임은 전적으로 사용자 본인에게 있다.
