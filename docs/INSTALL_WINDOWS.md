# Windows 설치 안내 — 키움증권 REST API AI 단타

이 프로그램은 **AI 단타 자동매매** 전용이다. 대형주와 주요 ETF만 대상으로,
AI(Claude Opus 5.5)가 분봉 흐름을 보고 진입 시점과 손절가·목표가를 판단한다.
프로그램은 그 판단을 검증한 뒤 1회 손실 한도(총 투입 금액의 0.5%)에 맞춘
수량으로 매수하고, 손절·익절로 청산한 뒤 다음 자리를 찾아 반복한다.
장전부터 장후까지 동작한다 — 국내 08:00~20:00(NXT),
미국은 주간거래+프리마켓+정규장에서 매수한다(애프터마켓에서는 새로 사지 않는다).

## 가장 쉬운 방법: 원클릭 설치

1. 저장소의 `scripts/AutoTrader-Setup.bat`를 바탕화면에 내려받아 더블클릭한다.
   (SmartScreen 경고가 뜨면 "추가 정보 → 실행")
2. 설치가 끝나면 메모장으로 `config.ini`가 열린다. 아래 "API 키 발급"에서
   받은 두 키를 붙여넣고 저장한다.
3. 바탕화면의 **"AutoTrader 실행"**을 더블클릭하면 브라우저에 대시보드가 열린다.

## API 키 발급 (키움증권, 최초 1회)

1. [openapi.kiwoom.com](https://openapi.kiwoom.com) 접속 → 키움 REST API 사용 신청.
2. 모의투자 신청 후 **모의투자용 appkey / secretkey** 발급.
3. `%USERPROFILE%\autotrader\config.ini`에 붙여넣는다:

   ```ini
   [kiwoom]
   appkey = 발급받은키
   secretkey = 발급받은시크릿
   mode = mock
   us_day_session = true   ; 미국주식을 한국 낮(주간거래)에도 매매

   [claude]
   backend = auto          ; AI 매매 판단: 키가 있으면 API, 없으면 구독 로그인
   api_key =               ; 구독 로그인을 쓰려면 비워 둔다
   model = claude-opus-5-5 ; 판단 모델 (비우면 Opus 5.5)
   effort = medium         ; 판단 강도 low / medium / high

   [universe]
   add =                   ; 종목군에 더할 종목 (쉼표로 구분)
   remove =                ; 종목군에서 뺄 종목

   [strategy]
   fee_pct = 0.07          ; 편도 수수료 % (화면 손익에서 뺀다. 비우면 미국 0.07 / 국내 0.015)
   sell_tax_pct = 0        ; 매도 시 세금 %
   ```

   이전 버전에서 만든 `config.ini`는 그대로 써도 된다. `model`·`effort`와
   `[universe]`가 없으면 기본값(Opus 5.5, medium, 대형주·주요 ETF)으로 동작한다.

## AI 매매 판단: 구독 로그인 (API 과금 없음)

Claude API 키 대신 claude.ai **Pro/Max 구독**으로 판단을 돌린다(기본 방식).

1. PowerShell에서 Claude Code 설치: `irm https://claude.ai/install.ps1 | iex`
2. `claude`를 한 번 실행해 claude.ai 계정으로 로그인 (브라우저 인증)
3. `[claude] api_key`는 비워 둔다 — 키가 없으면 자동으로 구독 로그인을 쓴다.

AI를 쓸 수 없으면 기본 설정에서는 매수를 쉰다(대시보드의 "AI 판단 필수"를
끄면 등락률 상위로 대체 — 권장하지 않는다). Claude Code가 PATH에 없어도 기본
설치 위치(`%USERPROFILE%\.local\bin\claude.exe` 등)를 직접 찾는다.

- 판단 한 번에 10~20초가 걸린다. 빈 자리가 있을 때 2분마다 진입 판단, 보유
  중일 때 4분마다 청산 점검을 요청한다.
- 구독에는 사용 한도가 있다. 한도에 걸리면 새로 사지 않고, 보유 종목은
  프로그램의 손절·목표 규칙으로 계속 관리한다. 대시보드의 "AI 매매 판단 근거"
  칸에 사유가 표시된다.
- `api_key`에 값이 있으면 API 방식(건당 과금)으로 바뀐다. 구독으로만 쓰려면
  비워 두거나 `backend = cli`로 고정한다.

## 사용 방법

대시보드에서 입력하는 값은 다음과 같다.

| 항목 | 기본값 | 의미 |
|---|---|---|
| 시장 | — | 국내주식 / 미국주식 |
| 목표 수익 % | 2 | AI가 목표가를 주지 않을 때 쓰는 기본 목표. 목표가에 닿으면 바로 익절한다 |
| 최대 손절 % | 2 | AI가 종목마다 손절가를 정하되 이 폭보다 멀리 두지 못한다. 손절가에 닿으면 무조건 전량 매도 |
| 1회 손실 한도 % | 0.5 | 한 번 손절했을 때 잃는 금액이 총 투입 금액의 이 %를 넘지 않게 수량을 정한다 |
| AI 판단 필수 | 켬 | 켜면 AI 판단을 받을 수 없을 때 매수를 쉰다 |
| 레버리지 ETF 포함 | 켬 | TQQQ·SOXL 같은 지수형 레버리지·인버스 ETF를 후보에 넣는다 |
| 동시 종목 | 2 | 동시에 보유할 최대 종목 수 (종목당 금액 상한 = 총액 ÷ 이 값) |
| 총 투입 금액 | — | 매수에 쓸 전체 금액 |

동작 규칙:

- **대형주와 주요 ETF만 산다.** 등락률·거래량 상위에 있어도 종목군에 없으면
  사지 않는다(종목군은 `config.ini`의 `[universe]`로 조정).
- AI가 진입 상한가·손절가·목표가를 제시하고, 프로그램이 검증한다. 판단이 90초
  넘게 지났거나 가격이 0.4% 넘게 움직였으면 버리고, 상한가보다 비싸면 쫓아 사지
  않는다. 목표 폭이 1% 미만이거나 손절 폭의 1.2배에 못 미쳐도 사지 않는다.
- 수량은 "1회 손실 한도 ÷ 손절 폭"으로 정한다. 예: 총액 $10,000, 한도 0.5%($50),
  주가 $200, 손절가 $198이면 25주. 총액이 작으면 1~2주만 사거나, 1주만 사도
  한도를 넘는 종목은 건너뛴다.
- 목표가에 닿으면 바로 익절한다.
- 수익이 손절 폭만큼 나면 손절가를 본전 위(매입가 + 0.3%)로 올린다.
- 보유 종목은 4분마다 AI가 점검해 손절가를 올리거나 조기 청산을 제안한다.
  AI는 손절가를 낮출 수 없고, 올리는 것도 수익이 손절 폭만큼 난 뒤에만
  가능하다(현재가에서 0.5%는 떨어뜨린다).
- 매도 주문은 매수호가에 맞춰 바로 체결되게 낸다. 15초 안에 안 받아지면
  취소하고 조금 낮춰 다시 낸다.
- AI가 "살 자리가 없다"고 이어서 답하면 묻는 간격을 2분에서 6분까지 늘린다.
- 화면의 실현손익은 수수료(편도 0.07%)를 뺀 값이고, 미국주식은 실제 체결가로
  기록한다.
- 각 장이 시작된 뒤 15분 동안, 그리고 끝나기 1시간 전부터는 매수하지 않는다.
- 호가 간격이 0.3%보다 넓거나 호가를 확인하지 못하면 사지 않는다.
- 같은 종목을 직전 매수가보다 비싸게 다시 사는 것은 하루 1회까지다.
- 손절한 종목은 30분, 익절한 종목은 5분 동안 다시 사지 않는다.
- 보유 종목이 60분 안에 손절·목표에 닿지 않으면 정리하고 교체한다.
- 당일 누적 손실이 총액의 2%에 달하거나 매매가 20회를 넘으면 그날은 신규
  매수를 멈춘다(보유 청산은 계속, 다음 거래일 재개).
- AI의 판단과 매매 결과는 `autotrader_journal_us.jsonl`(국내는 `_kr`)에 쌓인다.

## 장 마감 가드 (마감 1시간 전)

각 장이 끝나기 1시간 전부터 신규 매수를 멈추고, 그 시점에 남은 보유는 전량
정리한다. 겨울(미국 서머타임 해제) 기준 한국시간 매수 가능 구간:

| 시장 | 장 | 장 시간 | 신규 매수 | 보유 정리 |
|---|---|---|---|---|
| 미국 | 주간거래 | 10:00~18:00 | ~17:00 | 17:00 |
| 미국 | 프리마켓 | 18:00~23:30 | ~22:30 | 22:30 |
| 미국 | 정규장 | 23:30~06:00 | ~05:00 | 05:00 |
| 미국 | 애프터마켓 | 06:00~ | 없음 | — |
| 국내 | 장전(NXT) | 08:00~09:00 | 없음 | — |
| 국내 | 정규장 | 09:00~15:30 | ~14:30 | 14:30 |
| 국내 | 장후(NXT) | 15:30~20:00 | ~19:00 | 19:00 |

미국 서머타임 기간에는 미국 장 시각이 1시간씩 당겨진다(자동 판정).
국내 장전은 1시간짜리라 이 규칙상 매수하지 않는다.

## 계좌 보유 종목 처리 (실계좌 보유 패널)

대시보드의 "실계좌 보유 종목" 표에 계좌 보유가 1분마다 표시된다.

- **본전 감시**: 손실 중인 종목을 손절하지 않고 실시간으로 지켜보다가
  손익분기점(매입단가 + 0.3% 수수료 여유)에 닿으면 전량 매도한다. 손실 종목에만
  버튼이 보인다. 표 위의 **"손실 종목 모두 본전 감시"**를 누르면 손실 중인
  보유 종목이 한꺼번에 들어간다.
- **감시 해제**: 본전 감시를 끝낸다. 팔지 않고 그대로 두며 프로그램은 그 종목을
  더 이상 건드리지 않는다.
- **관리 편입**: 그 종목을 프로그램 관리 대상으로 넣는다. 매입단가 기준으로
  익절(+목표%)·손절(-손절%)·시간초과 규칙이 즉시 적용되며, 이미 손절선 아래면
  바로 손절 매도된다. 손실이 큰 종목은 관리 편입 대신 본전 감시를 쓴다.
- **즉시 매도**: 보유 수량 전부를 지금 매도한다(미체결 시 추격 매도).
- 편입하지 않은 보유는 프로그램이 절대 건드리지 않는다.

본전 감시에서 알아 둘 점:

- 손절·시간초과·장 마감 정리가 적용되지 않는다. 주가가 더 내려가도 팔지 않으므로
  손실이 커질 수 있고, 손익분기점까지 돌아오지 않을 수도 있다.
- 프로그램이 실행 중이고 장이 열려 있을 때만 감시한다. 프로그램을 다시 시작해도
  감시 목록은 이어진다.
- 매도 주문은 손익분기점 아래 가격으로 내지 않는다. 45초 안에 체결되지 않으면
  취소하고 다시 감시한다(가격을 낮춰 쫓아가지 않는다).
- 감시 종목은 "동시 종목" 자리를 차지하지 않아 AI 단타는 그대로 이어진다.
- HTS·MTS에서 직접 팔면 1~2분 안에 감시가 자동으로 끝난다.
- 프로그램이 꺼져 있는 동안 이미 손절선 아래로 내려간 프로그램 매수 종목은,
  다시 시작할 때 손절하지 않고 자동으로 본전 감시로 들어간다. 손절하려면
  "즉시 매도"를 누른다.

## 실전투자 전환

1. openapi.kiwoom.com 에서 **실전용** appkey/secretkey를 발급받아
   `config.ini`에 입력하고 `mode = real`로 바꾼다.
2. 대시보드의 "실전 확인"란에 `YES`를 입력해야만 시작된다.

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "API 키가 없다" | `config.ini`에 appkey/secretkey 입력 여부 확인 |
| "토큰 발급 실패" | 키가 모드(모의/실전)와 일치하는지, REST API 승인 여부 확인 |
| 매수가 안 나감 | 장중인지, 상태 카드에 한도 도달 표시가 있는지 확인 |
| "AI 판단 불가"가 나옴 | PowerShell에서 `claude`를 실행해 로그인 상태 확인. 사용 한도 안내가 보이면 한도가 풀릴 때까지 기다린다 |
| 매수가 거의 없음 | 정상일 수 있다. AI가 마땅한 자리가 없다고 판단하면 사지 않는다(판단 근거 칸에 이유 표시) |
| "1회 손실 한도를 넘는다"며 건너뜀 | 총 투입 금액이 작아 1주도 한도 안에 들어오지 않는다. 총액이나 한도 %를 올린다 |
| Python 설치 후에도 인식 안 됨 | 컴퓨터 재시작 후 설치 파일 재실행 |

## 유의사항

- 이 프로그램은 수익을 보장하지 않는다. AI가 단기 주가를 맞힌다는 근거는
  없으며, 단타는 매매가 잦아 수수료·호가 비용이 빠르게 쌓인다(화면의 손익은
  설정한 수수료율로 계산한 추정치이며 환전 비용은 포함하지 않는다).
  반드시 모의투자에서 충분히 검증한 뒤 실전 전환을 검토하라.
- API 키는 `config.ini`(내 컴퓨터)에만 두고 절대 저장소·메일 등에 올리지 않는다.
- 자동매매 결과의 책임은 전적으로 사용자 본인에게 있다.
