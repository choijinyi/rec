# Windows 설치 안내 — 키움증권 REST API 분할매매

이 프로그램은 **분할매수·분할매도 자동 집행** 전용이다. 사용자가 정한
종목·기준 가격·분할 %·분할 횟수·총 투입 금액대로, 기준 가격에서부터
정해진 %만큼 내려갈 때마다 자동 분할매수, 올라갈 때마다 자동 분할매도를
수행한다. 파이썬 표준 라이브러리만으로 동작한다.

## 가장 쉬운 방법: 원클릭 설치

1. 저장소의 `scripts/AutoTrader-Setup.bat`를 바탕화면에 내려받아 더블클릭한다.
   (SmartScreen 경고가 뜨면 "추가 정보 → 실행")
2. 설치가 끝나면 메모장으로 `config.ini`가 열린다. 아래 "API 키 발급"에서
   받은 두 키를 붙여넣고 저장한다.
3. 바탕화면의 **"AutoTrader 실행"**을 더블클릭하면 브라우저에 대시보드가 열린다.

## API 키 발급 (키움증권, 최초 1회)

1. [openapi.kiwoom.com](https://openapi.kiwoom.com) 접속 → 키움 REST API 사용 신청.
2. 모의투자 신청 후 **모의투자용 appkey / secretkey** 발급.
3. `%USERPROFILE%\autotrader\config.ini`에 붙여넣는다:

   ```ini
   [kiwoom]
   appkey = 발급받은키
   secretkey = 발급받은시크릿
   mode = mock
   us_day_session = true   ; 미국주식을 한국 낮(주간거래)에도 매매
   ```

`mode = mock`이면 모의투자 서버(mockapi.kiwoom.com)로만 접속한다.

## 사용 방법

대시보드에서 입력하는 값은 여섯 가지다.

| 항목 | 의미 |
|---|---|
| 종목코드 | 국내 `005930`, 미국 `AAPL` 형식 |
| 기준 가격 | 분할의 출발점. 현재가가 이 가격 이하로 오면 1차 매수 |
| 분할 % | 레벨 간격. 예: 3이면 3%마다 |
| 매수 분할 | 몇 번에 나눠 살지 (1차는 기준가, 2차는 -3%, 3차는 -6% ...) |
| 매도 분할 | 몇 번에 나눠 팔지 (1차 +3%, 2차 +6% ...) |
| 총 투입 금액 | 매수에 쓸 전체 금액. 각 매수는 이 금액 ÷ 매수 분할 |

동작 규칙:

- 각 분할 레벨은 **1회만** 집행된다. 가격이 여러 레벨을 한 번에 지나가면
  해당 레벨들을 모두 집행한다(그 몫들을 더 유리한 가격에 사는 셈이다).
- 매도 수량은 보유 수량을 남은 매도 횟수로 나눈 만큼이며, 마지막 매도는
  전량이다.
- 모든 레벨이 끝나고 보유가 0이 되면 "완료"로 자동 멈춘다. 같은 계획을
  다시 돌리려면 값을 확인하고 다시 시작을 누른다.
- 장중에만 동작한다. 국내 09:00~15:30, 미국은 정규장(한국시간 밤)과
  주간거래(`us_day_session = true`일 때, 한국 낮) 시간.
- 미국주식 주문은 시장가 코드가 없어 직전 시세 기준 지정가로 집행된다.

## 실전투자 전환

실전투자는 이중 확인을 거쳐야 실행된다.

1. openapi.kiwoom.com 에서 **실전용** appkey/secretkey를 발급받아
   `config.ini`에 입력하고 `mode = real`로 바꾼다.
2. 대시보드의 "실전 확인"란에 `YES`를 입력해야만 시작된다.

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "API 키가 없다" | `config.ini`에 appkey/secretkey 입력 여부 확인 |
| "토큰 발급 실패" | 키가 모드(모의/실전)와 일치하는지, REST API 승인 여부 확인 |
| 주문이 안 나감 | 장중인지, 기준 가격이 현재가와 맞게 설정됐는지 확인 |
| Python 설치 후에도 인식 안 됨 | 컴퓨터 재시작 후 설치 파일 재실행 |

## 유의사항

- 이 프로그램은 수익을 보장하지 않는다. 분할매수는 하락이 계속되면
  손실도 분할로 쌓인다는 뜻이다. 기준 가격과 총 투입 금액을 신중히 정하라.
- API 키는 `config.ini`(내 컴퓨터)에만 두고 절대 저장소·메일 등에 올리지 않는다.
- 자동매매 결과의 책임은 전적으로 사용자 본인에게 있다.
