# 레크리에이션 지도 — 집필 자료 아카이브

『레크리에이션 지도』 단행본 집필을 위해 구글 드라이브에 흩어져 있던 자료를 한곳에 모은 저장소다.
원본은 최진이(chlwlsdl@gmail.com) 개인 드라이브이며, 2017년 숭실사이버대학교 「레크리에이션활동」
강의부터 2025년 서울한영대학교 「레크리에이션지도」 강의까지의 축적물을 담고 있다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `01_강의계획서_시험` | 강의계획서(2025), 기말고사 문제지, 주차별 개요 정리 |
| `02_레크리에이션지도_강의안` | 서울한영대 「레크리에이션지도」 연도별 강의안(2022~2025) |
| `03_레크리에이션활동_강의안` | 숭실사이버대 「레크리에이션활동」 1~14주차 강의안 및 학습필수요소 |
| `04_교재_원고` | 치료레크리에이션·레크스포츠지도 원고, 유아 레크리에이션 진행법 |
| `05_특강_워크숍_현장자료` | 수련회 팀빌딩, 청소년 집회, 광주 레크지도자 과정, AI 활용 워크숍 |
| `06_게임_아이스브레이크` | 게임 99가지, 아이스브레이크, 그룹워크, 리더십 자료 |
| `07_NCS_게임지도` | NCS 기반 레크리에이션과 교육과정 개발 보고서, 게임지도 강의계획서 |
| `_manifest` | 수집에 사용한 드라이브 파일 ID 목록 |

## 자료의 성격과 집필 활용 방향

강의안은 연도별로 개정되며 축적되어 왔다. 같은 주제라도 2022년판과 2025년판의 서술이 다르므로,
집필 시에는 최신판을 본문의 기준으로 삼고 이전 판은 서술 변화의 근거로 참고하는 편이 좋겠다.

내용 축은 대체로 다음 다섯 갈래로 나뉜다.

1. **여가의 개념과 역사** — 스콜레(scholē)·오티움(otium)의 어원, 고대 그리스·로마부터 정보화
   시대까지의 여가사(史). 2024·2023년 1강, 2강 강의안에 집중되어 있다.
2. **여가 이론과 측정** — 여가 동기, 여가 제약과 대체용이성, 몰입(flow), 진지한 여가(serious
   leisure)와 레크리에이션 전문화. 3강 계열 자료와 기말고사 문항에서 개념 목록을 확인할 수 있다.
3. **생애주기별 여가와 실버레크리에이션** — 유아기부터 노년기까지, 고령사회 대응. 4강 및 마지막
   강의안 계열.
4. **레크리에이션 지도 실제** — 리더십, 프로그래밍, 게임 지도, 아이스브레이크, 팀빌딩.
   `03`, `05`, `06`, `07` 폴더가 여기에 해당한다.
5. **치료레크리에이션과 응용** — 치료레크리에이션 원고, 유머테라피, 인지재활 영역.

## 수집에서 제외한 자료

용량이 크거나 책의 본문 자료로 쓰기 어려운 것들은 링크만 남기고 파일은 가져오지 않았다.

- 동영상 자료(레크댄스, 무대게임, 실버레크리에이션 시연, 웃음치료 등 mp4·wmv)
- 게임 진행용 실행파일(`.exe` 형식의 퀴즈·아이스브레이크 프로그램)
- 300MB~1GB에 이르는 동영상 임베드 pptx(같은 내용의 PDF가 있는 경우 PDF로 대체)
- 학사 행정 문서(성적표, 정산서, 명단, 회의록 등)

전체 후보 목록은 `_manifest/`의 파일 ID 목록으로 되짚어 볼 수 있다.

## 파일 형식에 관한 메모

일부 문서는 원본 바이너리 대신 텍스트를 추출한 `.md` 파일로 저장되어 있다. 원본이 필요하면 각
`.md` 첫머리에 적힌 드라이브 링크에서 내려받으면 된다.

## 10MB를 넘어 가져오지 못한 자료

자동 수집에 쓴 드라이브 연동 도구는 한 번에 10MB까지만 내려받는다. 그보다 큰 파일은 `자료목록.md`에
링크만 남겼으니, 브라우저에서 직접 내려받아 해당 폴더에 넣으면 된다. 그중 아래 두 건은 책의 뼈대가
될 만한 원고이므로 우선 챙기는 편이 좋겠다.

- 치료레크리에이션(최종) — 28MB, `04_교재_원고/`
- 레크스포츠지도(최종) — 26MB, `04_교재_원고/`
