# autotrader — AI 단타 자동매매 프로그램

거래량·등락률 상위 후보를 **AI(Claude Fable)가 분석해 매매 종목을 자동
선정**하고, 키움증권 REST API로 **손절(-2%) / 목표(+2%) 도달 후 고점을
따라가며 익절**하는 단타 프로그램이다. 청산으로 자리가 비면 다시 종목을 찾아
같은 매매를 이어 간다. 파이썬 표준 라이브러리만으로 동작한다(AI는 Claude
Code 구독 로그인 또는 API 키).

## 동작 방식

1. 거래량 상위·등락률 상위 후보를 모아 필터링한다 (상승 모멘텀, 초저가·
   저유동성 제외, 쿨다운 제외, 오늘 더 싸게 샀던 종목의 추격 재매수 제외).
2. Fable이 후보를 분석해 매수 종목을 고른다. 적합한 종목이 없으면 "없음"으로
   답하고 매수를 쉰다. **AI를 쓸 수 없을 때도 기본값은 매수를 쉬는 것**이다
   (대시보드의 "AI 선정 필수"를 끄면 등락률 상위로 대체한다).
3. 매수 직전 **호가 간격**을 확인해 0.3%보다 넓으면 사지 않는다. 통과하면
   매도호가에 지정가로 산다(슬롯당 예산 = 총 투입 금액 ÷ 동시 종목 수).
4. **-손절 % 도달 → 무조건 전량 손절.** **+목표 % 도달 → 바로 팔지 않고 추적
   익절**을 시작해, 고점에서 0.7% 밀릴 때 판다(추세가 이어지면 더 길게 보유).
   60분 동안 어느 쪽에도 닿지 않으면 정리하고 교체한다.
5. 슬롯이 비면 1번으로 돌아가 반복한다.

손익비를 이렇게 둔 이유: 초기 설정(목표 +1.5% / 손절 -3%)은 한 번 지면 두 번
이겨야 메워져 승률 67% 이상이 필요했고, 실전 12회에서 승률 42%로 손실이 났다.
손절은 대시보드에서 바꿀 수 있으며 기본값은 -2%다(목표보다 넓게 두지 않는다).

## 매매 시간 (장전~장후)

- **국내**: 08:00~20:00. 정규장(09:00~15:30)은 KRX 시장가,
  장전·장후는 NXT(대체거래소) 직전 시세 지정가로 집행한다.
- **미국**: 주간거래(한국 낮) + 프리마켓 + 정규장 + 애프터마켓 —
  평일 기준 사실상 24시간 연속. 프리/애프터마켓은 직전 시세 지정가로
  집행되며, 유동성이 얇아 체결이 느릴 수 있다.

## 안전장치

- **장 마감 가드**: 각 장(국내 장전·정규장·장후 / 미국 주간거래·프리마켓·
  정규장·애프터마켓)이 끝나기 1시간 전부터 신규 매수를 멈추고, 그 시점에
  남은 보유는 손익과 관계없이 전량 정리한다("장마감 정리"). 마감 직전에
  사서 팔지 못하고 물리는 것을 막는다. 다음 장이 열리면 자동 재개한다.
- **체결 확인 후에만 장부 반영(미국)**: 지정가 주문은 미체결 조회로 체결을
  확인하기 전까지 포지션을 지우지 않는다. 매도가 45초 안에 안 받아지면
  취소하고 현재가보다 조금씩(0.3%p씩, 최대 2%) 낮춰 다시 내는 추격 매도로
  손절을 끝까지 집행한다. 주문이 사라져도 실계좌 보유로 실제 매도를 재확인한다.
- **저유동성 배제**: 거래대금(가격×거래량)이 미국 $1,000만 / 국내 100억 원 미만이거나
  거래량이 미국 50만 주 / 국내 30만 주 미만인 종목은 후보에서 뺀다 — 매도가 안 받아져 손절이 막히는 것을 막는다.
- **실계좌 보유 패널**: 대시보드에서 계좌 보유 종목을 보고 "본전 감시",
  "관리 편입"(익절·손절 규칙 적용), "즉시 매도"를 고를 수 있다. 사용자가
  고르지 않은 기존 보유는 손대지 않는다.
- **본전 감시(손실 보유 종목)**: 손실 중인 보유 종목을 손절하지 않고 실시간으로
  지켜보다가, 손익분기점(매입단가 + 0.3% 수수료 여유)에 닿으면 전량 매도한다.
  손절·시간초과·장 마감 정리를 적용하지 않고 매매 자리(동시 종목)도 차지하지
  않는다. 매도 주문은 손익분기점 아래로 내지 않으며, 체결되지 않으면 가격을
  낮추지 않고 다시 감시한다. 손절이 없으므로 감시하는 동안 손실이 더 커질 수
  있다.
- **재시작해도 포지션 유지**: 프로그램이 산 포지션은 `autotrader_state_us.json`
  에 저장되고, 재시작 시 실계좌와 대조해 감시를 이어 간다.
- **개장 직후 대기**: 각 장이 시작된 뒤 15분 동안은 매수하지 않는다.
- 당일 누적 손실이 총 투입 금액의 6%에 달하면 신규 매수 중단(청산은 계속),
  다음 거래일에 자동 재개.
- 당일 매매 횟수 제한(기본 40회), 손절 종목 재매수 30분 대기, 같은 종목을
  직전 매수가보다 비싸게 다시 사는 것은 하루 1회까지.
- `mode = mock`(모의투자)이 기본. 실전은 `mode = real` + 대시보드 `YES`
  입력의 이중 확인. 미국주식은 1분마다 실계좌 잔고와 장부를 동기화한다.
- AI 선정 중에도 보유 포지션 감시(익절/손절)는 멈추지 않는다(백그라운드 탐색).

## 실행

```bash
python -m autotrader ui        # 브라우저 대시보드 (127.0.0.1 전용)
```

대시보드에서 시장(국내/미국), 목표 수익 %, 손절 %, 동시 종목 수, 총 투입
금액을 입력하고 시작을 누른다. 보유 포지션(실시간 수익률),
오늘 매매 성적(승/패·실현손익), Fable 선정 근거가 실시간으로 표시된다.

**원클릭 설치(Windows)**: [scripts/AutoTrader-Setup.bat](scripts/AutoTrader-Setup.bat)를
바탕화면에 내려받아 더블클릭. 자세한 안내는
[docs/INSTALL_WINDOWS.md](docs/INSTALL_WINDOWS.md) 참고.

테스트 실행:

```bash
python -m unittest discover -s tests -v
```

## 유의사항

자동매매는 수익을 보장하지 않으며 원금 손실 위험이 있다. 단타는 매매가
잦아 수수료·호가 비용이 빠르게 쌓이고, 통계적으로 수익을 내기 어려운
방식이다. 반드시 모의투자에서 충분히 검증한 뒤 실전 전환을 검토해야
하며, 투자 결과의 책임은 사용자에게 있다. AI 선정은 참고 자료일 뿐
투자 자문이 아니다.
