# autotrader — AI 단타 자동매매 프로그램

**대형주와 주요 ETF**만 대상으로, **AI(Claude Opus 5.5)가 분봉 흐름을 보고
진입·청산 시점을 판단**하는 키움증권 REST API 단타 프로그램이다. AI는 제안만
하고, 주문 집행·손절·수량 계산은 코드가 맡는다. 파이썬 표준 라이브러리만으로
동작한다(AI는 Claude Code 구독 로그인 또는 API 키).

## 동작 방식

1. **종목 관문** — 거래대금·거래량·등락률 순위에서 후보를 모으되,
   [허용 종목군](autotrader/universe.py)(대형주·지수/섹터 ETF·지수형 레버리지
   ETF)에 있는 종목만 남긴다. 등락률 1위라도 목록에 없으면 사지 않는다.
2. **진입 판단(AI)** — 상위 후보 6개의 1분봉을 요약(VWAP, 당일 고저, 5·15·60분
   수익률, 최근 종가·거래량)해 AI에 넘긴다. AI는 종목마다 진입/대기/제외를
   고르고, 진입이면 **진입 상한가·손절가·목표가**를 제시한다. 마땅한 자리가
   없으면 아무것도 사지 않는다.
3. **검증(코드)** — AI 제안을 그대로 믿지 않는다.
   - 판단이 나온 지 90초가 지났거나 그사이 가격이 0.4% 넘게 움직였으면 버린다.
   - 현재가가 진입 상한가보다 높으면 쫓아 사지 않는다.
   - 손절 폭은 0.4%~최대 손절 %(기본 2%) 안으로 맞춘다.
   - 목표 폭이 1% 미만이거나 손절 폭의 1.2배에 못 미치면 사지 않는다.
   - 호가 간격이 0.3%보다 넓으면 사지 않는다.
4. **수량(코드)** — 손절까지 갔을 때 잃는 금액이 **총 투입 금액의 0.5%**(1회
   손실 한도)를 넘지 않도록 수량을 정한다. 손절이 먼 종목은 자동으로 적게 산다.
5. **청산** — 손절가에 닿으면 무조건 전량 매도. 수익이 손절 폭만큼 나면
   손절가를 본전 위로 올린다. 목표가에 닿으면 바로 팔지 않고 고점에서 0.7%
   밀릴 때 판다. 60분 안에 어느 쪽에도 닿지 않으면 정리한다.
6. **청산 점검(AI)** — 보유 종목을 4분마다 AI가 다시 본다. 유지, 손절가 상향,
   즉시 청산 가운데 하나를 고른다. **AI는 손절가를 올릴 수만 있고, 낮추거나
   없앨 수 없다.**

AI가 응답하지 않으면(로그인 풀림, 사용 한도 등) 새로 사지 않고, 보유 종목은
코드의 손절·목표 규칙으로 계속 관리한다.

## 왜 이렇게 바꿨나

- 등락률 상위에서 종목을 집던 방식은 주식병합을 반복하는 초소형주를 끌어들였고,
  팔고 싶어도 받아 줄 상대가 없어 손절이 막혔다. 그래서 종목군을 먼저 막는다.
- 자금을 종목 수로 똑같이 나누던 방식은 위험한 종목에도 같은 금액을 실었다.
  그래서 수량을 "잃어도 되는 금액 ÷ 손절 폭"으로 정한다.
- AI의 응답은 10~20초가 걸린다. 틱 단위 대응은 코드(3초 주기)가 하고, AI는
  분 단위 판단만 맡는다.

## AI 호출

- 기본은 **Claude Code 구독 로그인**(건당 과금 없음, 구독 사용 한도 적용)이며
  모델은 `claude-opus-5-5`, 판단 강도는 `medium`이다. 실측 응답 시간은 호출당
  12~17초였다.
- `config.ini`의 `[claude]`에서 바꿀 수 있다: `model`, `effort`(low/medium/high),
  `backend`(auto/cli/api), `api_key`(API 방식일 때만. 건당 과금).
- 호출 빈도: 빈 자리가 있을 때 2분마다 진입 판단 1회, 보유 중일 때 4분마다
  청산 점검 1회.

## 매매 시간 (장전~장후)

- **국내**: 08:00~20:00. 정규장(09:00~15:30)은 KRX 시장가,
  장전·장후는 NXT(대체거래소) 직전 시세 지정가로 집행한다.
- **미국**: 주간거래(한국 낮) + 프리마켓 + 정규장 + 애프터마켓 —
  평일 기준 사실상 24시간 연속. 프리/애프터마켓은 직전 시세 지정가로
  집행되며, 유동성이 얇아 체결이 느릴 수 있다.

## 안전장치

- **종목군 제한**: 대형주·주요 ETF만 매매한다. `config.ini`의 `[universe]`에서
  `add`/`remove`로 조정하고, 대시보드에서 레버리지 ETF를 뺄 수 있다.
- **1회 손실 한도**: 총 투입 금액의 0.5%(대시보드에서 변경).
- **당일 한도**: 누적 손실이 총 투입 금액의 2%에 달하거나 매매가 20회를 넘으면
  신규 매수를 멈춘다(보유 청산은 계속, 다음 거래일 재개).
- **장 마감 가드**: 각 장이 끝나기 1시간 전부터 신규 매수를 멈추고, 그 시점에
  남은 보유는 손익과 관계없이 전량 정리한다.
- **체결 확인 후에만 장부 반영(미국)**: 지정가 주문은 미체결 조회로 체결을
  확인하기 전까지 포지션을 지우지 않는다. 매도가 45초 안에 안 받아지면 취소하고
  조금씩 낮춰 다시 내는 추격 매도로 손절을 끝까지 집행한다.
- **유동성·호가 필터**: 거래대금이 미국 $1,000만 / 국내 100억 원 미만이거나
  호가 간격이 0.3%보다 넓으면 사지 않는다.
- **개장 직후 대기**: 각 장이 시작된 뒤 15분 동안은 매수하지 않는다.
- **재매수 제한**: 손절 종목 30분 대기, 같은 종목을 직전 매수가보다 비싸게
  다시 사는 것은 하루 1회까지.
- **실계좌 보유 패널**: 계좌 보유 종목을 보고 "본전 감시", "관리 편입",
  "즉시 매도"를 고를 수 있다. 사용자가 고르지 않은 기존 보유는 손대지 않는다.
- **본전 감시**: 손실 중인 보유 종목을 손절하지 않고 지켜보다가 손익분기점
  (매입단가 + 0.3%)에 닿으면 전량 매도한다. 손절이 없으므로 손실이 더 커질 수
  있다.
- **재시작해도 포지션 유지**: 포지션과 손절가·목표가는 `autotrader_state_us.json`
  에 저장되고, 재시작 시 실계좌와 대조해 감시를 이어 간다.
- `mode = mock`(모의투자)이 기본. 실전은 `mode = real` + 대시보드 `YES`
  입력의 이중 확인.

## 판단 기록

AI의 진입 판단, 매수, 청산 점검, 매매 결과가 `autotrader_journal_<시장>.jsonl`
에 한 줄씩 쌓인다. 어떤 판단이 이익으로, 어떤 판단이 손실로 이어졌는지 나중에
복기하는 데 쓴다.

## 실행

```bash
python -m autotrader ui        # 브라우저 대시보드 (127.0.0.1 전용)
```

대시보드에서 시장, 목표 수익 %, 최대 손절 %, 1회 손실 한도 %, 동시 종목 수,
총 투입 금액을 입력하고 시작을 누른다. 보유 포지션(손절가·목표가 포함),
오늘 매매 성적, AI 판단 근거가 실시간으로 표시된다.

**원클릭 설치(Windows)**: [scripts/AutoTrader-Setup.bat](scripts/AutoTrader-Setup.bat)를
바탕화면에 내려받아 더블클릭. 자세한 안내는
[docs/INSTALL_WINDOWS.md](docs/INSTALL_WINDOWS.md) 참고.

테스트 실행:

```bash
python -m unittest discover -s tests -v
```

## 구조

| 모듈 | 역할 |
|---|---|
| `autotrader/scalper.py` | 매매 엔진: 후보 수집, AI 제안 검증, 수량 계산, 청산, 안전장치 |
| `autotrader/analysis.py` | AI 진입 판단·청산 점검 (구독 로그인 / API) |

| `autotrader/kiwoom_rest.py` | 키움 REST API (시세·분봉·주문·순위·잔고) |
| `autotrader/webui.py` | 로컬 웹 대시보드 |

## 유의사항

자동매매는 수익을 보장하지 않으며 원금 손실 위험이 있다. AI가 단기 주가를
맞힌다는 근거는 없다 — 기대할 수 있는 것은 나쁜 진입을 걸러내는 것과 규율을
지키는 것이다. 단타는 매매가 잦아 수수료·호가 비용이 빠르게 쌓인다(프로그램이
표시하는 손익에는 수수료가 빠져 있다). 반드시 모의투자에서 충분히 검증한 뒤
실전 전환을 검토해야 하며, 투자 결과의 책임은 사용자에게 있다. AI 판단은 참고
자료일 뿐 투자 자문이 아니다.
